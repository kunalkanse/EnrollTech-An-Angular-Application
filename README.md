# EnrollTech

EnrollTech is an Angular app that allows users to find and enroll in IT courses. It uses Angular, RxJS, NgRx, Forms, Directives, Pipes, Routing, and Token-based Authentication for seamless navigation, efficient state management, and smooth data flow, providing an interactive learning experience.

## Key Technologies Used:

- **Angular**: The core framework for building the application with components, services, and modules.
- **RxJS**: Used for reactive programming, handling asynchronous operations like HTTP requests.
- **NgRx**: For state management, providing a store for maintaining application state across components.
- **Angular Forms**: Implemented for managing forms and handling user inputs securely.
- **Directives & Pipes**: Custom directives for DOM manipulation and pipes for data transformation.
- **Routing**: Angular Router used for navigation between different pages and views.
- **Token-Based Authentication**: JWT (JSON Web Tokens) authentication used to securely manage user logins, ensuring that only authenticated users can access protected routes and enroll in courses.
- **Services**: Angular services are used to manage HTTP requests, state management, and interaction with backend APIs.

## Features:

- **Search and Enroll in IT Courses**: Browse through available courses and easily enroll.
- **Secure Authentication**: Login functionality with token-based authentication using JWT to securely manage sessions.
- **State Management**: Efficient state handling using NgRx to ensure consistent data flow across components.
- **Responsive Design**: The application is fully responsive, providing a smooth user experience across devices.

## Installation
### Backend Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/enrolltech.git

2. Navigate to the backend project directory:
    ```bash
    cd server

3. Install server dependencies:
    ```bash
    npm install

4. Start the backend server:
    ```bash
    npm start

### Frontend Setup
1. Navigate to the frontend project directory:
    ```bash
    cd angular-fundamentals-template

2. Install dependencies:
    ```bash
    npm install

### Run the application
1. Start the Angular application:
     ```bash
     npm start

2. Navigate to http://localhost:4200 in your browser to access the frontend.
